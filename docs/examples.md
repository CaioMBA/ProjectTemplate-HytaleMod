# Placement Examples

Use these examples when deciding where code should live.

- Hytale command class -> `platform/command`
- Hytale event handler -> `platform/event`
- Algorithm/calculation -> `core/service/algorithms`
- Config validation -> `core/service/validation`
- File reading/writing -> `core/infrastructure/data/filesystem`
- External HTTP/API client -> `core/infrastructure/data/api`
- Public API contract -> `api`
- Domain entity -> `core/domain/entities`
- Value object -> `core/domain/valueobjects`
